Desenvolvido na disciplina de **Desenvolvimento Web com React** da residência em software do **Serratec (2021)**.

Painel do administrador do petshop. A loja do cliente está em [petshop](https://github.com/ramosth/petshop).

## Funcionalidades

- 🔐 **Login** do administrador
- ➕ **Cadastro de produtos** (POST)
- 📋 **Listagem de produtos e serviços** (GET)
- 🗑️ **Exclusão de produtos** (DELETE)
- Rotas com **React Router** e chamadas HTTP com **Axios**

## Como executar

```bash
npm install
npm start
```

A aplicação abre em `http://localhost:3000`.

> A API de back-end era disponibilizada pela disciplina e rodava localmente em `http://localhost:8000`.
